hash2(x) = N - 2 - x % (N - 2)

posição = (hash1(x) + i × hash2(x)) % N

o que aconteceria se tivesse que inserir mais um número na posição 8, por exemplo?

usamos hash2(x) = N - 2 - x % (N - 2) para posição, de forma simplificada, a linha completa é

posição = (hash1(x) + i × hash2(x)) % N

nos casos acima o i = 1 depois da primeira colisão, na segunda rodada.
aplicaria novamente a fórmula fazendo um incremento no i

posição = (hash1(x) + 2 × hash2(x)) % N

a formula matematica oficial da dupla dispersão possui a variavel i, tentativa/pulo, mas se olhar 
o laco while faz o papel da multiplicacao atraves da acumulacao

matematicamente, somar o salto varias vezes eh exatamente a mesma coisa que multiplicar por i

Aluno* insere2 (Hash tab, int mat, char* nome) {
    // mat = 80
    int h = hash(mat);   // h = 0
    int h2 = hash2(mat); // h2 = 8

    //inicio do laco
    
    //tentativa 0
    //o computador pergunta, se tab[0] estah ocupada? sim
    //o 10 está lah, entra no laço
    while (tab[h] != NULL) { 
        if (tab[h]->mat == mat) break; // 10 nao eh 80, continua
        
        //tentativa 1, matematicamente i=1
        //calcula o novo h somando o salto
        h = (h + h2) % N; 
        // O novo h agora vale 8!
    }

    //fim da primeira volta no laco
    //o while volta lah para cima e avalia a nova posicao
    //computador pergunta, tab[8] estah ocupada? sim
    //40 estah lah, entra no laco de novo
    while (tab[h] != NULL) { 
        if (tab[h]->mat == mat) break; //40 nao eh 80, continua
        
       	//tentativa 2, matematicamente i=2
        //h atual é 8, salto h2 eh 8
        //calcula o novo h, (8 + 8) % 10  ->  16 % 10
        h = (h + h2) % N; 
        //novo h agora 6
    }

    //fim da segunda volta no laco
    // while volta lah para cima e avalia a nova posicao
    //computador pergunta, tab[6] está ocupada, nao, estah vazia, NULL
    //condição tab[h] != NULL eh falsa, o laço while eh quebrado e finalizado

    //código continua aqui em baixo em h valendo 6
    if (tab[h] == NULL) { 
        tab[h] = (Aluno*) malloc(sizeof(Aluno)); //aloca a caixinha na posicao 6
        tab[h]->mat = mat;                       //guarda o 80 lah dentro
    }
    
    strcpy(tab[h]->nome,nome);
    return tab[h];
}
