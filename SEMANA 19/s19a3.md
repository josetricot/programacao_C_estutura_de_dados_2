Considerando o conceito de Inserção com Dupla Dispersão em Tabelas Hash, insira as chaves: 10, 20, 30 e 40, utilizando as seguintes funções de Dupla Dispersão (i = tentativa e N=10):

&#x20;

hash1(x) = x % 10

hash2(x) = N - 2 - x % (N - 2)

posição = (hash1(x) + i × hash2(x)) % N

i na verdade é o pulo, quando existe colisão

posição = (hash1(x) + i × hash2(x)) % N

posição = (hash1(x) + 0 × hash2(x)) % N

posição = (hash1(x)) % N
